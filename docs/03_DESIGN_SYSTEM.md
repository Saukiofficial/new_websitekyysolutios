# 03 — Design System

## 1. Design Direction

KyySolutions harus terlihat:
- modern,
- professional,
- technology-focused,
- trustworthy,
- clean,
- conversion-oriented.

Hindari tampilan marketplace yang terlalu ramai.

## 2. Brand

Brand: **KyySolutions**

Gunakan logo dan brand assets resmi setelah tersedia.

## 3. Core UI

Komponen utama:
- Button
- Input
- Select
- Search
- Card
- Product Card
- Seller Card
- Badge
- Modal
- Drawer
- Dropdown
- Tabs
- Table
- Pagination
- Toast
- Alert
- Empty State
- Skeleton
- Breadcrumb
- Pricing block
- Review component

## 4. Marketplace UI

Product card minimal:
- image,
- title,
- price,
- seller,
- rating,
- category/tech tag,
- optional sale badge.

Product detail harus memiliki CTA yang jelas.

## 5. Responsive

Prioritas:
- mobile,
- tablet,
- desktop.

Desktop dapat menggunakan sidebar untuk dashboard.
Mobile menggunakan navigation yang sesuai konteks, misalnya bottom navigation atau compact menu.

Jangan hanya mengecilkan layout desktop. Setiap breakpoint harus mempertimbangkan:
- navigation,
- spacing,
- card grid,
- forms,
- tables,
- modal/drawer,
- checkout,
- seller dashboard.

## 6. Accessibility

- semantic HTML,
- keyboard accessible,
- visible focus,
- readable contrast,
- clear error messages,
- form labels.

## 7. Interaction

Gunakan animation secukupnya:
- hover,
- transition,
- modal,
- dropdown,
- page feedback,
- loading state.

Animation tidak boleh mengganggu checkout atau navigasi.

## 8. Consistency Rule

Jangan membuat komponen baru jika komponen existing dapat digunakan atau diperluas secara aman.
