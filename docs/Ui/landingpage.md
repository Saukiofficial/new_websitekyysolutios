# Landing Page Design Specification — KyySolutions

## 1. OBJECTIVE

Redesign the existing KyySolutions landing page into a **premium international-level digital agency + digital products marketplace landing page**.

The design must feel:

* Modern
* Premium
* Professional
* Clean
* Trustworthy
* Technology-focused
* Conversion-oriented
* Similar in quality to international SaaS, software agency, and digital product marketplace websites

Do NOT make the website look like a generic Indonesian company landing page.

The visual direction should combine:

**Modern SaaS + Digital Agency + Digital Marketplace**

The design should prioritize:

1. Strong visual hierarchy
2. Excellent whitespace
3. Premium typography
4. Clear CTA hierarchy
5. Consistent card design
6. Professional responsive behavior
7. Strong visual storytelling
8. High perceived brand value

# 3. OVERALL VISUAL STYLE

Use a **premium modern SaaS aesthetic**.

Avoid:

* Excessive gradients
* Excessive rounded elements
* Cartoon-like illustrations
* Overly colorful sections
* Cheap-looking shadows
* Excessive animations
* Huge typography that consumes the entire screen
* Dense layouts
* Generic Bootstrap-like appearance

Use:

* White backgrounds
* Deep navy text
* Blue as the primary brand color
* Purple/indigo as a secondary accent
* Very subtle gradients
* Soft shadows
* Thin borders
* Large whitespace
* Clean cards
* Consistent 12-column grid
* Rounded corners around 10–16px
* Premium modern typography

# 5. TYPOGRAPHY

Use a modern international SaaS font.

Preferred:

**Inter**

Alternative:

**Manrope**

Typography must have excellent readability.

Recommended hierarchy:

Hero Heading:

* 56–72px desktop
* 42–48px tablet
* 34–40px mobile
* Weight: 700–800
* Tight line-height: approximately 1.05–1.12

Section Heading:

* 36–44px desktop
* 30–34px tablet
* 26–30px mobile

Card Heading:

* 16–18px
* Weight 600–700

Body:

* 14–16px
* Line-height 1.6–1.75

Do not use excessively bold typography throughout the page.

Use bold typography only for hierarchy.

# 23. SPACING SYSTEM

Use consistent spacing.

Section padding desktop:

```text
80px – 120px
```

Section padding mobile:

```text
56px – 72px
```

Between heading and subtitle:

```text
12px – 16px
```

Between subtitle and content:

```text
32px – 48px
```

Cards:

```text
16px – 24px padding
```

Avoid sections being visually compressed.

Whitespace is a major part of the design.

---

# 24. BORDER RADIUS

Use a consistent radius system.

Small:

```text
8px
```

Buttons:

```text
8px – 10px
```

Cards:

```text
12px – 16px
```

Large visual containers:

```text
16px – 24px
```

Do not use 30–40px radius everywhere.

The design should feel professional rather than playful.

---

# 25. SHADOW SYSTEM

Use extremely subtle shadows.

Example:

```text
0 4px 20px rgba(15, 23, 42, 0.06)
```

Hover:

```text
0 12px 30px rgba(15, 23, 42, 0.10)
```

Never use heavy black shadows.

---

# 26. BUTTON DESIGN

Primary button:

* Blue background
* White text
* 8–10px radius
* Medium weight
* Small arrow icon

Example:

**Explore Services →**

Secondary:

* White background
* Border
* Dark text

Buttons should have:

* Hover state
* Active state
* Focus state
* Disabled state

Animation:

150–250ms.

---

# 27. ICONOGRAPHY

Use one consistent icon library.

Recommended:

Lucide Icons.

Icons should be:

* Minimal
* Outline based
* Consistent stroke width
* Approximately 16–22px

Never mix random icon styles.

---

# 28. ANIMATION

Use subtle professional animations.

Allowed:

* Fade-up on section entry
* Slight card lift
* Image scale on hover
* Button arrow movement
* Navigation transition
* Hero floating cards
* Smooth scrolling

Avoid:

* Excessive bouncing
* Large rotations
* Flashing
* Continuous distracting animations
* Long loading animations

Animation duration:

```text
150ms – 500ms
```

Use animation only where it improves the experience.

---

# 29. RESPONSIVE DESIGN

Responsive behavior is mandatory.

## Desktop

At least:

```text
1280px+
```

Use:

* Full navigation
* Two-column hero
* 4-column services
* 4-column marketplace
* 6-step horizontal process
* 3-column portfolio
* 4-column metrics

## Tablet

Around:

```text
768px – 1279px
```

Use:

* Compact navigation
* Two-column hero when space allows
* 2-column services
* 2-column portfolio
* 2-column products
* Wrapped process

## Mobile

Below:

```text
768px
```

Use:

* Mobile navigation
* One-column hero
* Hero visual below text
* 1-column service cards
* Horizontal product carousel or 1-column grid
* Vertical process timeline
* 1-column portfolio
* 2-column statistics
* Stacked CTA buttons
* Mobile-friendly footer

# 33. CONTENT DENSITY

The current design feels slightly too dense.

Redesign it with:

* More whitespace
* Shorter descriptions
* Stronger headings
* Fewer words per card
* More visual hierarchy

Users should understand each section within 2–4 seconds.

The page should be highly scannable.

---

# 34. IMAGE STYLE

All project and product imagery should look like:

* Premium SaaS mockups
* Modern dashboards
* Professional business applications
* Clean device mockups
* High-quality UI screenshots

Avoid:

* Random stock photos
* Low-resolution images
* Generic office photos
* Images with inconsistent lighting
* Images with unrelated visual styles

Portfolio images should feel like they belong to the same brand.

---

# 35. DESIGN CONSISTENCY

Every component must follow the same design language.

Maintain consistency in:

* Border radius
* Shadows
* Typography
* Icon style
* Button style
* Card spacing
* Colors
* Image ratios
* Container widths
* Section spacing

Do not design each section independently.

The entire page must feel like one cohesive product.

---

# 36. ACCESSIBILITY

Implement:

* Proper semantic HTML
* Accessible buttons
* Keyboard navigation
* Visible focus states
* Sufficient color contrast
* Alt text for images
* Proper heading hierarchy
* Accessible mobile navigation

Do not sacrifice accessibility for visual appearance.

---

# 37. PERFORMANCE

The landing page should be optimized for performance.

Use:

* Lazy loading for below-the-fold images
* Optimized image sizes
* Responsive images
* Minimal animation overhead
* Efficient component rendering
* No unnecessary JavaScript
* Avoid huge image assets

Hero assets should be optimized because they are above the fold.

---

# 39. IMPORTANT DESIGN RULES

These rules are mandatory:

1. Do not copy the reference website literally.
2. Use the reference only as visual inspiration.
3. Improve the visual hierarchy.
4. Make the design look more premium than the existing version.
5. Use more whitespace.
6. Reduce visual noise.
7. Keep typography sophisticated.
8. Do not overuse gradients.
9. Do not overuse rounded corners.
10. Keep cards simple and elegant.
11. Maintain consistent alignment.
12. Make the hero visually impressive.
13. Prioritize conversion.
14. Make every section responsive.
15. Do not create horizontal scrolling on mobile.
16. Do not use excessive animations.
17. Maintain excellent contrast.
18. Use professional SaaS visual patterns.
19. Keep the design scalable for future content.
20. Do not break existing functionality.
